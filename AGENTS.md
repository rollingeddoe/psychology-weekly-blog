# Psychology Weekly — English blog

This is the public website repository, separate from the private psychology-weekly editorial workspace.

- Do not copy research pools, local backups, credentials, source full texts, or unapproved issue drafts into this repository.
- Keep work-in-progress research in the private editorial workspace. A public Git repository exposes even files marked draft.
- Publish research articles only after the user approves that English version. Approval of a Chinese issue does not approve its translation automatically.
- Site framework and introductory site copy are authorized by the user's request to build the blog.
- Use English, clear complete paragraphs, verified metadata, and APA references. Do not invent author credentials or research findings.
- All links must respect the GitHub Pages base path. Draft/future content must be excluded consistently from article routes, archive, RSS, and sitemap.
- Build and check internal links before pushing. A push to main publishes the approved content automatically.
